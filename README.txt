ABUL Elektronik Service — V4
=============================

VERSI INI SENGAJA DIBUAT SATU FILE:
- Semua foto/logo sudah tertanam langsung di index.html.
- Tidak ada folder images yang harus di-upload.
- Tidak ada style.css atau script.js terpisah.
- Upload HANYA index.html ke repository GitHub Pages.
- Ini menghindari masalah gambar tidak tampil karena path/folder.

CARA UPLOAD:
1. Hapus file website lama dari repository (index.html, images, style.css, script.js).
2. Upload file index.html V4 ini ke root repository.
3. Pastikan nama file tepat: index.html (huruf kecil).
4. Settings -> Pages -> Deploy from branch -> main -> / (root).
5. Tunggu 1-3 menit lalu lakukan Ctrl+F5 di browser.
